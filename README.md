# 7x7 Stories

Canonical public site: https://bosshtw.github.io/7x7-stories/

The home page is the resource map, followed by stories, feedback and guide information. `project/` preserves the former landing page’s brand assets and updated project guidance. This hub is public, with no private team files.

Static GitHub Pages deployment from `main` at the repository root; no build step. Start locally with `python3 -m http.server 8765`.

Resource listings: `data/resources.json`. Map, filters and email-draft forms: `app.js`. Story content: `stories/`. Appearance: `style.css`, `theme.css`, `theme.js`, `story.css`. Brand downloads and animation: `project/`.

The former 7x7-resource-atlas site redirects here, including query strings and fragment links. Legacy hub fragments at the main URL redirect to `project/`.
